# Federal HACS — study materials

A public study set for the **GSA MAS Highly Adaptive Cybersecurity Services**
special item number (**SIN 54151HACS**) oral technical evaluation — and, more
broadly, for anyone learning the U.S. federal cybersecurity compliance stack.

It's a give-back: I built the private version to prepare for a HACS oral
evaluation, and distilled the reusable, public-standards part into these three
documents so the next person studying doesn't start from a blank page.

| Document | Use it for |
|---|---|
| [`cheat-sheet.md`](cheat-sheet.md) | **Recall** — the numbers, acronyms, and framework tables on one page |
| [`study-guide.md`](study-guide.md) | **Understanding** — the five HACS services and the frameworks explained so you can reason, not just recite; plus how to deliver the oral |
| [`flashcards.md`](flashcards.md) | **Practice** — question-and-answer decks for out-loud drilling |

## What this covers

The federal stack a HACS evaluation tests: the **RMF** (NIST 800-37) and the road
to an **ATO**; **NIST 800-53 Rev 5** control families; **FedRAMP** and the role of
an independent **3PAO**; **CMMC**; **FIPS 199/200**; **Zero Trust** (CISA ZTMM
v2.0 / OMB M-22-09); the adversary frameworks (**MITRE ATT&CK**, **STRIDE**,
**PTES**); and the five HACS services — **HVA Assessment, RVA, Penetration
Testing, Incident Response, and Cyber Hunt** — with their methodologies (**NAR**,
**IHEM**).

## Two honest caveats

- **Verify the current revision before you quote a number.** Standards move —
  800-61 is on **r3 (2025)**, CSF is on **2.0**, CISA Zero Trust on **v2.0**.
  Where a revision changed the answer, the materials show both and flag which is
  current; quoting the retired version is the clearest "studied from an old PDF"
  tell.
- **These are public standards, not a shortcut past understanding them.** The
  study guide exists precisely because memorizing the cheat sheet is not the same
  as being able to reason to an answer a question asks sideways.
